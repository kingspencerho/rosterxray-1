## I. Structural Framework & Core Rules

> **Callout — Draft Mandates**
> - **Conditional Forced Stacking Protocol**: Reach 1+ rounds early ONLY for High Scarcity (Tier 1 QB / elite TE that won't survive the turn). Reach 0.5–1 round for High Volatility loop WRs if a position run is likely. Hold for ADP value on Low Scarcity / deep pools.
> - **Week 15 Elimination Filter**: This is the steepest cut (1/10 in Puppy). Roster must clear it on ceiling, not floor. DAL @ LAR (52.5) is the unambiguous S-tier anchor — elite across W15/16/17.
> - **Naked RB Insulation**: Unstacked RBs need HVT (red zone/goal-line volume) or elite zone-scheme + PROE signal to be rosterable.

### Pivot Trigger Checklist (applies globally — check weekly)
- [ ] **Pace/PROE Shift**: Team's neutral-script pace or PPP drops below league median, OR a new/interim OC materially shifts PROE → downgrade tier by one notch, re-evaluate stack.
- [ ] **HVT/Role Dilution**: Primary target's snap share or HVT splits into a strict 50/50 committee with no financial/scheme signal → swap primary loop target, keep game environment if total holds.
- [ ] **Total Volatility**: Game total drops below 44 → downgrade from High-Leverage to Hidden Upside (or cut entirely if paired with a top-5 defensive suppression unit). Game total rises 3+ pts from baseline → consider upgrading a Hidden Upside game to High-Leverage.
- [ ] **Defensive Suppression**: Opposing defense graded historically elite (top-3 DVOA + low pace-allowed) → flag game as "Wall Risk" regardless of total.
- [ ] **Injury to Anchor Piece**: Primary stack QB/WR1 lost for multiple weeks → re-grade entire game environment's draft priority, do not assume backup replicates role.
